# Orbit Voice 0.1.0-alpha.1

First public alpha of an independent Wear OS voice assistant with an Android
companion and official OpenAI open-source account authorization. No API key entry.

## Included

- Watch speech recognition, streamed text responses, sentence-based spoken output
  and automatic next-turn listening with stop/interrupt controls.
- Official browser OAuth with PKCE, dynamic client registration, signed ID-token
  validation, model discovery and token renewal on the phone.
- Account-separated Keystore-encrypted local history, resume, delete and Markdown export.
- A round-screen watch UI, quick-launch Tile provider and original adaptive icon.
- Complete MIT-licensed source, Gradle wrapper and GitHub Actions build workflow.

## Install

Install the **phone APK on an Android 11+ phone** and the **wear APK on a Wear OS
watch running Android API 30+**. Pair them through the normal manufacturer/Wear OS
companion. Both APKs must come from this release. They share the application ID
for Data Layer communication and must not be installed together on one device.

On the phone, choose **Continue with ChatGPT**, complete the eligible account/plan
consent flow and select a model. On the watch, use **Options → Refresh connection**,
then **Start talking**. Speech services and installed TTS voices are required.

## Verification and alpha limits

- 29 JVM tests passed.
- 13 instrumented tests passed on an Android 16 phone emulator, covering storage,
  navigation and synthetic local HTTPS request/stream/cancellation behavior.
- Both lint tasks and signed release builds passed locally.
- Offline round-screen controls were checked on a 384×384 Wear OS 6 emulator.
- Both release APK signatures were verified with the same certificate. File
  digests are in the attached `SHA256SUMS.txt`.

**Real OpenAI browser authorization and inference, paired physical phone/watch
transport, full spoken conversation, and Tile host rendering have not been
verified.** This is an early alpha, not a production-readiness claim. Account
eligibility, usage limits, speech availability and device background policy apply.

History stays on the phone and does not appear in ChatGPT. This uses Android
speech services plus Responses HTTP/SSE; it does not implement native ChatGPT
Voice or Realtime Audio through the account grant. The user accepted local history.
