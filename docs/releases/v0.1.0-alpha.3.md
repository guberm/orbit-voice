# Orbit Voice 0.1.0-alpha.3

Third alpha. The watch now keeps working while the phone app is closed, a watch-face
shortcut joins the tile, and speech recognition no longer loses a quietly spoken phrase.

## Included

- **Resident phone companion.** The watch request service is started once from the phone app
  (or after an app update), stays in the foreground and is re-armed after a reboot, so a watch
  turn never has to start a service from the background. Android 12 and later forbid that
  background start, which is why earlier builds asked the user to open the phone app first.
  An ongoing low-priority notification shows that the phone is ready. The service type is
  `connectedDevice`, which has no daily runtime cap.
- **Watch-face shortcut.** A complication provider so Orbit Voice can sit on the watch face:
  one tap opens the conversation screen already listening. The Tile in the tiles carousel
  behaves the same way. Wear has no API for an app to add its own tile or complication, so
  both are placed by the user.
- **Recognition fixes.** A quietly spoken phrase could be dropped before it ever reached the
  phone: the capture gate needed several consecutive frames above its threshold, and frames
  before the gate opened were discarded, which was exactly where the speech was. The pre-roll
  now keeps three seconds, the gate accumulates instead of resetting, and only the silence
  before the phrase is trimmed. Verified on a Pixel Watch 3: `decode samples=42880 ms=4080`,
  `lang=ru`, "Проверка связи." and a spoken Russian answer.
- **Faster answers.** The speech engine's voice is switched and warmed as soon as the
  recognized language is known: the first spoken sentence starts about 2.6 s after the answer
  text instead of 5.2 s.
- **Stability.** Fixed a null decoder that left a watch turn without a reply, a launch that
  failed while the speech engine was still binding, a relaunch that ignored the tile's
  start-voice extra, and an ANR caused by speech-engine calls on the UI thread.
- Recognized text is never written to the system log, and no audio is ever written to disk.

## Install

Install the **phone APK on an Android 11+ phone** and the **wear APK on a Wear OS watch running
Android API 30+**, then pair them through the normal manufacturer/Wear OS companion. Both APKs
must come from this release: they share the application ID for Data Layer communication and must
not be installed together on one device.

On the phone, select **Continue with ChatGPT**, complete the eligible account/plan consent flow
and choose a model, then leave **Speech language** on **Automatic** for offline multilingual
recognition. On the watch, open Orbit Voice and tap **Start talking**. Add the Tile from the
watch's tile selector, or place the Orbit Voice shortcut on the watch face.

## Verification and alpha limits

- 40 JVM tests passed (`:core:test`), including the speech endpoint set that covers a quiet
  utterance barely above the room noise, obvious silence, a tap and the ten-second cap.
- Measured on a Pixel 9 Pro XL and a Pixel Watch 3: the watch session starts with the phone UI
  closed, the account and model come from the resident phone service, and a Russian phrase is
  transcribed and answered.
- The resident service was observed in the foreground (`isForeground=true`,
  `types=0x00000010`) with the launcher in front, armed by the update broadcast alone.
- Latency of one turn: audio transfer 0.15-1.0 s, decoding 3.7-4.1 s, OpenAI first token
  2.8-4.1 s, speech start 2.6 s - roughly ten seconds from the end of a phrase to the first
  spoken word. A quieter, faster model or streaming the audio while recording are the next
  options; both change accuracy or architecture.

**Still unverified:** a complete spoken dialogue without pauses, the boot path
(`adb` cannot send the protected `BOOT_COMPLETED` broadcast, so only the app-update path is
proven), watch-face shortcut rendering by a specific watch face, and latency, battery and
thermal behaviour across a longer conversation.

History stays on the phone and does not appear in ChatGPT. This release does not implement
native ChatGPT Voice or Realtime Audio through the account grant.
